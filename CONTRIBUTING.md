# Contributing

Applicant Desk Autofill aims to be a useful, privacy-preserving form helper for many kinds of web forms.

## Before opening a pull request

- Keep the extension Manifest V3 compatible.
- Request the narrowest permissions needed for the feature.
- Do not add remote code, analytics, advertising, or a backend that receives profile data.
- Do not add support for passwords, authentication cookies, payment details, or CAPTCHA solving.
- Update the privacy policy when data handling changes.
- Run the syntax and package checks described in the README.

When adding a field alias, include a small example in the pull request description and explain why the alias is unambiguous.
