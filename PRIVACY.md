# Privacy policy

**Applicant Desk Autofill** is a local-only Chrome extension for filling compatible web-form fields at the user's request.

## Data handled

The extension may store information the user enters or imports, including names, contact details, addresses, education, test scores, and recommendation-contact details. When the user chooses **Fill this page**, it reads form labels and fields on the active page only to identify compatible fields.

## Use and sharing

The data is used only for the extension's single purpose: filling compatible fields. It is not sold, used for advertising or profiling, or sent to a developer-operated server. The extension has no backend.

## Storage and deletion

Profile data is stored in Chrome local storage on the user's device. Removing the extension or clearing its storage removes the stored profile. The extension does not transmit profile data or page content to third parties.

## Permissions

- storage: save the user's profile locally.
- activeTab: temporarily access the page the user explicitly chooses to fill.
- scripting: run the packaged field-matching code after that action.

The extension uses no remote code. These permissions are the minimum needed for the current feature.

## Limited Use statement

The extension's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the user-facing autofill function, is not transferred to third parties, and is not used for advertising.
