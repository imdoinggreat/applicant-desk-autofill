# Security policy

## Scope

Applicant Desk Autofill is designed to keep profile data on the user's device. The extension has no backend and does not ask for passwords, payment information, or authentication cookies.

## Reporting a vulnerability

Please open a private security report through the GitHub repository once the project is published. Do not post personal data, credentials, or application-form contents in a public issue.

## Supported versions

The latest published version is the only supported version. Before reporting, please reproduce the issue with the latest Chrome stable release and the latest extension package.
