Applicant Desk Autofill Privacy Policy

Last updated: 2026-09-10

Applicant Desk Autofill is a local-only browser extension that helps users reuse information they provide when completing web forms.

Information handled

The extension may store profile information that the user enters or imports, such as names, contact details, addresses, education, test scores, and recommendation-contact details. When the user chooses “Fill this page,” it reads form labels and fields on the active page only to identify compatible fields.

How information is used

Information is used only to provide the extension’s single purpose: filling compatible form fields at the user’s request. The extension does not sell, advertise with, profile, or remotely analyze this information.

Storage and sharing

Profile information is stored in Chrome local storage on the user’s device. The extension has no backend and does not transmit profile data or page content to the developer or any third party. The user can remove local data by removing the extension or clearing its storage in Chrome.

Permissions

  • storage: save the profile locally in Chrome.
  • activeTab: temporarily access the page the user actively chooses to fill.
  • scripting: run the local field-matching code after that user action.

These permissions are limited to the extension’s single purpose. No remote code is loaded or executed.

Contact

For questions or security reports, use the contact method listed on the project’s GitHub repository.
